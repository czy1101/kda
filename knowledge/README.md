# KDA optimization knowledge base

This is reusable, evidence-scoped optimization guidance. Start with the target
index and read only cards relevant to the current bottleneck and language.

| Target | Index |
|---|---|
| Enflame S60 / GCU300, Triton or Torch | [Enflame knowledge](enflame/README.md) |

Knowledge cards suggest hypotheses; they do not replace the task contract,
current-environment tool discovery, separate correctness tests, benchmark
measurements, or checkpoint/promotion gates. A compiler path observation is
not a hardware utilization measurement. An old speedup is not a new result.

Keep raw task artifacts in their original workspaces. Cards may reference
those artifacts, but must remain useful when local evidence is unavailable.
Use the [card template](enflame/CARD_TEMPLATE.md) and preserve negative results
as well as successful mechanisms. Repository documentation is in English.
